# Security policy

## Supported versions

Only the latest release of Dive Lens, on the [Releases page](https://github.com/Ventrilok/divelens/releases), receives security fixes.

| Version | Supported |
|---|---|
| Latest release | Yes |
| Earlier releases | No |

## Reporting a vulnerability

Report it privately, in one of two ways:

- on GitHub: the repository's **Security** tab › **Report a vulnerability** ([direct link](https://github.com/Ventrilok/divelens/security/advisories/new));
- by e-mail to [divelens@querton.com](mailto:divelens@querton.com).

**Never in a public issue, pull request or discussion**: everyone can read them, forever.

Say what the problem is, how to reproduce it, and which Dive Lens version and system you use. Do not include a real dive log or any other personal data: describe it in words instead.

## Reporting an exposed secret

If you find a key, certificate, password or token in the repository, in its history or in a release, report it the same way, privately, without repeating it anywhere public. Deleting it in a new commit does not remove it from history: it has to be revoked.
